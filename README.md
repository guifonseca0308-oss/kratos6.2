# Kratos PS2 Launcher

Aplicativo desktop Windows para abrir o PCSX2 com um jogo selecionado pelo usuário.

## Executar

```powershell
npm.cmd install
npm.cmd start
```

No primeiro uso, localize o executável do PCSX2 instalado e selecione seu arquivo de jogo. O launcher guarda esses caminhos no perfil local do aplicativo; ao clicar em JOGAR novamente, inicia o jogo salvo.

Se o PCSX2 não estiver instalado, o launcher abre a página oficial de downloads. A BIOS deve ser obtida legalmente pelo usuário e configurada no PCSX2. O launcher não distribui nem baixa BIOS ou jogos.
